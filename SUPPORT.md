# Goku Support

For Goku support, bug reports, and feature requests, use the public issue tracker:

<https://github.com/jmogainz/goku-ios/issues>

Before opening an issue, remove server URLs, credentials, private chat content, file contents, logs containing secrets, and other personal information.

For upstream Hermex behavior that is unchanged in Goku, the upstream project remains available at <https://github.com/uzairansaruzi/hermex>.
